# Demand and supply of oil

A standalone interactive game for the oil market. Students build a four-step story: short-run supply, goods made from oil, demand for oil, and the long run. Each step shifts demand or supply, shows excess demand or excess supply at the old price, then moves to a new equilibrium.

## Open locally

Open `index.html` in a browser. No install or build step is needed.

## Upload to GitHub

1. Create a new empty repository on GitHub (for example `demand-and-supply-of-oil`).
2. In this folder, run:

```bash
git init
git add index.html diagram-economist.css README.md
git commit -m "Add demand and supply of oil game"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/demand-and-supply-of-oil.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.

## GitHub Pages

In the repo: **Settings → Pages → Deploy from a branch → main**, folder `/`.

The live game will use `index.html` as the home page.
